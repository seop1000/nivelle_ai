# 실시간 오디오 분석

## 구성과 실행 경계

실시간 분석은 Link PC에서만 실행된다. 마이크 데이터는 Core나 모델로 전송하지 않으며
AI 의미 분류와 자동 행동도 수행하지 않는다. 기존 파일 분석 탭과 서버 분석 API는 그대로
유지된다.

```text
Qt QAudioSource
  -> 최대 8개 청크의 제한 큐
  -> PCM 모노 변환
  -> 1초 고정 크기 링 버퍼
  -> NumPy 분석 워커
       |- 파형 envelope
       |- RMS / Peak / dBFS
       |- FFT / 주요 주파수
       |- 정규화 자기상관 F0
       `- STFT 스펙트로그램 열
  -> 최신 결과 슬롯
  -> 40ms UI 타이머
```

캡처 callback은 수신 바이트를 제한 큐에 넣는 작업만 한다. PCM 변환과 모든 분석은 하나의
daemon worker에서 실행되므로 Qt UI 이벤트 루프를 막지 않는다. UI가 늦어질 때는 과거
청크를 무한히 쌓지 않고 가장 오래된 청크를 버린다.

## 입력 장치와 오디오 형식

- Qt가 보고하는 모든 오디오 입력 장치를 선택할 수 있다.
- 우선 48,000 Hz의 Float 또는 16-bit PCM 형식을 요청한다.
- 장치가 이를 지원하지 않으면 장치의 실제 기본 형식을 사용하고 UI에 실제 샘플레이트를
  표시한다.
- UInt8, Int16, Int32, Float PCM을 지원하며 다채널 입력은 분석용 모노로 평균한다.
- 실행 중 장치를 선택하면 캡처와 worker를 정리한 뒤 새 장치로 즉시 전환한다.
- 사용 중인 장치가 분리되면 분석만 중지하고 오류를 표시한다. Link 전체는 종료하지 않는다.

## 분석 설정

| 항목 | 설정 |
|---|---|
| FFT 창 | 4,096 샘플 Hann window |
| FFT hop | 2,048 샘플 |
| 48 kHz 분석률 | 약 23.4회/초 |
| 표시 주파수 | 20 Hz~20 kHz 또는 실제 Nyquist 중 작은 값 |
| 스펙트럼 표시점 | 최대 600개 |
| 스펙트로그램 | 로그 간격 128 bin, 최대 300개 시간 열 |
| 파형 | 최근 120ms, 최대 512개 min/max envelope |
| UI 주기 | 40ms, 최대 25 FPS |
| 오디오 링 버퍼 | 최근 1초 고정 크기 |

주요 주파수는 FFT에서 가장 강한 성분을 찾은 뒤 인접 bin 세 개로 포물선 보간한다. 짧은
EMA smoothing을 적용하고, -60 dBFS 미만의 무음이나 주변 스펙트럼보다 15 dB 이상
두드러지지 않는 입력에서는 `감지되지 않음`을 반환한다.

F0는 최근 80ms를 약 8 kHz로 낮춘 뒤 50~1,000 Hz lag 범위의 정규화 자기상관 local
peak를 사용한다. 상관 신뢰도 0.72 미만은 거부하고 포물선 lag 보간과 별도 EMA smoothing을
적용한다. 주요 주파수와 F0는 서로 독립된 값이다.

RMS와 Peak는 최근 hop 구간에서 계산하며 dBFS는 full scale 1.0 기준이다. Peak가 0.98
이상이면 클리핑으로 표시하고 -3 dBFS 이상이면 클리핑 주의를 표시한다.

## 정리와 오류 처리

`분석 중지`, 입력 장치 전환, 오디오 창 닫기와 Link 종료 시 다음 순서로 정리한다.

1. `readyRead` callback 연결 해제
2. `QAudioSource` 중지
3. worker stop event와 sentinel 전달
4. worker thread join
5. 제한 큐와 분석 링 버퍼 초기화

입력 장치 없음, 장치 분리, 지원하지 않는 PCM 형식, 캡처 시작 실패와 분석 예외는 실시간
분석 상태에만 오류로 표시된다.

## 제한사항

- 운영체제가 출력 loopback 장치를 입력 장치로 제공할 때만 시스템 재생음을 선택할 수 있다.
- dBFS는 디지털 full scale 기준이며 보정된 음압 레벨(dB SPL)이 아니다.
- F0는 음성이나 단일 음처럼 주기적인 입력을 위한 추정치다. 다성 음악과 소음에서는 값을
  표시하지 않거나 지각되는 음높이와 다른 값이 나올 수 있다.
- 마이크 권한은 Windows 개인정보 설정에서 허용되어 있어야 한다.
- 스펙트로그램은 최근 약 12.8초(48 kHz 기준)만 보존한다.
