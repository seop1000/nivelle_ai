# Dependencies

FastAPI/Uvicorn provide the gateway; Pydantic validates contracts and settings; aiosqlite provides async persistence; httpx/websockets implement upstream and client transports; PyYAML handles configuration; platformdirs chooses Windows data locations; psutil supplies portable telemetry; PySide6/qasync implement the responsive desktop UI; keyring targets Windows Credential Manager. pytest, pytest-asyncio, pytest-qt, Ruff, and mypy provide verification.
